# Research direction review — 2026-09-12

## Assessment and scope

There is useful partial mathematics here, but the latest sequence of
Green-function classifications is not yet a persuasive route to a prize
solution. No complete solution was found in this review.

Reviewed local main at `0ff6930`, GitHub PR history, and selected notes and
code from PR #256, cycle JP, commit
`5d7f6661fed11e82dfdf4faff3562138ddb4ef58`. This is a selective mathematical
review, not a validation of every cycle. GitHub reported 256 open PRs.
Main still ends at H; the latest branch's README still labels BG as its
last completed cycle even though that branch contains JP. Readers cannot
reliably find the current state from either landing page.

## What is worth keeping

- The constant-tail arguments and the strip-graph method exploit the
  actual Rule 30 update. The independently checked long-run certificate
  below strengthens the presentation of one existing partial result.
- The period-2 reconstruction isolates a concrete obstruction: whether a
  compatible reconstructed left half can have finite support. The later
  `period2_ugap.md` proof that the even right neighbor avoids both `11`
  and `00000` is an example of a useful uniform constraint. It already
  exists on GitHub; it is not a new suggestion from this review.
- Exact Green identities are useful tools, provided their unresolved
  nonlinear remainders stay explicit.

## Where the current direction stalls

Cycles JH–JP mostly classify Green support, local windows, reflection, and
doubling. These describe the coefficients of the linear propagation
kernel. The remainders J also contain the actual Rule 30 AND values at
the selected sites. Knowing the coefficients does not determine those
values or their XOR. Cycle JP explicitly acknowledges this same gap.

JH and JP were rerun successfully in a separate copy of the latest branch.
Their passing checks establish the advertised finite censuses and examples;
they are not an induction over all scales. For example, JH's `v2_table`
enumerates n < 64. A general theorem needs an argument from the doubling
recurrences, not simply the output label `LEMMA`. Likewise, a stored
predecessor JSON containing `all_ok` is a record of a check, not an
independently checked proof dependency.

The covering target also needs its exact payoff stated. Let

    phi_k(q) = c_(q*2^k) XOR c_(2^k),  q in {3,5,9}.

If at least one phi is 1 for infinitely many k, no eventual period 2^m
is possible. Full nonperiodicity does not follow: periods with an odd
factor remain. Cycle BE states this correctly. The later target that the
covering NEVER fails is stronger than necessary. Isolated failures would
not invalidate the infinitely-often route.

## A concrete proof repair

`isolated_zero_uniform.md`, Lemma F, infers that a long path must visit
the cruise self-loop from uniqueness of that self-loop. Uniqueness alone
does not exclude longer cycles or long transient paths. Lemma E's claim
that inserting onto relations preserves mixing also needs justification.
These are gaps in the written argument, not counterexamples to the desired
period exclusion.

There is a simpler proof of the exclusion for every q >= 9.

**Finite local lemma.** If a column has temporal word 1^9 0 1, its left
neighbor is 1 at the time of the zero.

Certificate: enumerate every 13-bit row on columns -6 through +6. Apply
Rule 30 literally to the eleven interior cells and allow both boundary
cells to vary freely at each step. Starting with every center-1 row,
successively impose nine center ones. The possible-row counts are

    4096, 3200, 2944, 2816, 2560, 2304, 2048, 1664, 1408.

Impose the zero. Of the resulting rows, 512 have left neighbor zero.
None of those 512 has a successor with center one. Rows with left
neighbor one do have such successors. This exhausts all strip paths,
including every restriction of a genuine Rule 30 spacetime.

The independent, standard-library certificate is
`review_long_run_certificate.py`. It imports none of the existing graph
or transition code.

**Uniform consequence.** In an eventual (01^q)-periodic column, q >= 9,
every sufficiently late zero has nine preceding ones and a following one.
The lemma forces its left neighbor to 1. At a center 1, the update gives
left_t = 1 XOR center_(t+1), so the left neighbor is determined there
as well. Both adjacent columns are eventually periodic, contradicting
Jen/Kopra for a nonzero finite seed. No enumeration over q is needed.

The same argument excludes any eventual periodic word whose zeros are
all separated by at least nine ones, including unequal run lengths.
No novelty is claimed. The q=7 exclusion was separately rerun with the
existing radius-6 SCC analyzer: one recurrent component, with a forced
periodic neighbor. This repair does not prove all the original claims
about SCC uniqueness, sizes, or graph periods; it proves the exclusion
that matters to the prize investigation.

## Recommended next work

1. Consolidate a current research entry point with exact statements,
   quantifiers, dependencies, and separate statuses for proved results,
   exhaustive finite certificates, sampled conjectures, and failed
   candidates. Preserve the chronological log as history. This is more
   useful than another PR containing one reflection identity.
2. Develop the temporal-context method into a small library of verified
   implications that force the left-neighbor bit. The 1^9 0 1 lemma is a
   concrete example. Target an additional infinite family of periodic
   words, using context implications to determine the neighbor at every
   phase. Surviving strip paths still need compatibility with the finite
   seed; no fixed-width method is promised to resolve period 2.
3. If retaining the Green route, require the next proposed lemma to
   constrain the seed's AND-weighted remainder under a scale change.
   Specify the joint observables, derive their update, and account for
   every new term. A coefficient-only symmetry or an equally difficult
   uncomputed remainder does not meet that milestone. Aim first for
   infinitely many successful covering scales, not success at every scale.

I would prioritize (1) and (2). The period-2 finite-support obstruction
remains a meaningful longer-term target, but the existing finite scans,
failed insulation estimate, and bounded-memory obstructions give no basis
for claiming that it is close to resolution.
